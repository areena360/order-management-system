# Quantity units and UI update

Each WooCommerce product line now creates one editable OMS production order per unit. Quantity 2 creates two rows. Customer order number remains the same; manufacturer order numbers remain unique. Multiple products split independently by stable WooCommerce line ID and unit number.

Retry and concurrent delivery do not duplicate units. Increasing quantity adds only missing units. Decreasing quantity or removing a line retains prior production rows and marks them for review in Order Details; production work is never silently deleted. Soft-deleted rows are not recreated. Limit: 1000 units per WooCommerce order.

The retail snapshot shows the complete WooCommerce order total on each row; this is explicitly labelled and must not be summed across unit rows. Manufacturing Amount remains independent.

Outbound sync sends one update per WooCommerce order. Status changes only when all non-deleted current unit rows have the same mapped status. Distinct tracking numbers are combined. Pagination operates on complete WooCommerce orders rather than units.
